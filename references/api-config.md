# 外部 API 配置（可选）

本技能的资料核验、风格规划、版式制作、素材拆分与 PPTX 组装不依赖外部 API。只有当你明确选择外部文本或图片生成服务时，才需要配置对应服务。

## 安全配置

- 优先使用本机环境变量；也可在本机创建未跟踪的 `config.json`。
- 不要把 API key 粘贴到对话、截图、文档示例或 Git 仓库。
- 不要打印或记录密钥明文。若密钥误提交，立即在服务商控制台撤销并轮换。
- 根据所选服务商当前官方文档设置 base URL、模型、认证方式、请求字段和输出解析。不同服务可能并不完全兼容 OpenAI 格式。
- 图片生成也可使用当前环境提供的内置图像生成能力；是否可用由当前运行环境决定，与本地 API key 配置分开。

## 示例配置

复制 `config.example.json` 到本机 `config.json` 后自行填写。示例中的端点与密钥都是占位值，不能直接调用。
